# Glossary

| Term | Definition |
|---|---|
| Bottleneck indikatif | Area sinyal risiko paling kuat/data paling tak jelas menurut aturan scoring; bukan kepastian |
| Belum cukup jelas | State saat selisih 2 skor teratas ≤10 atau data valid kategori bersaing < separuh indikator; tampil maks 2 area periksa |
| F/M/R/A/C | Dimensi diagnostik: Financial clarity, Margin & pricing, Retention, Reach, Capacity |
| S/G | Konteks saja di MVP: Stability & constraints, Goal & direction; tak ubah skor/akses |
| Growth levers | 4 lensa: margin & unit economics, retensi & relasi, reach & acquisition, capacity & operating system |
| Survival/Improvement/Growth | Tahap naratif roadmap statis; bukan gate/kelas user |
| Payload berversi | Jawaban survey + versi katalog + ringkasan diagnosis di `localStorage`; rusak → abaikan/hapus/minta ulang |
| M/H/V/Q/D/F/T | Kalkulator: margin, harga, biaya variabel, volume/hari, hari/bulan, biaya tetap/bulan, target laba/bulan |
| HPP | Biaya produksi per unit; jelaskan bahasa sehari-hari |
| Titik impas | `ceil(F/(M×D))` jika `M>0,D>0`; `0` jika `F=0` |
| Won't for MVP | Tak dibangun rilis ini, bukan larangan permanen |
